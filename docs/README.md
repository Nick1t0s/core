# Система сбора, индексации и поиска информации

Система состоит из четырёх частей:

- **скрапперы** собирают данные из внешних источников;
- **core** хранит, индексирует и выполняет поисковые запросы от агента;
- **балансировщик** забирает тяжёлые задачи (транскрибация, OCR, эмбеддинги) у источников задач (core и агента) и выполняет их на воркерах на GPU;
- **[агент](agent/README.md)** — единое приложение в одном контейнере: главный веб-интерфейс с ИИ-агентом, ручным поиском и управлением Telegram-ботом. Оба режима поиска доступны также в боте. Агент держит общую очередь тяжёлых задач для балансировщика и обращается к core за поиском.

Пример использования: спросить LLM «скинь ссылку, я вчера видел видео про asyncio» — ИИ-агент находит его через поисковый API core, используя фильтры и семантический поиск.

## Модели (на сентябрь 2026)

|---|---|

| Транскрибирование | whisper large-v3-turbo |
