# Система сбора, индексации и поиска информации

Система состоит из четырёх частей:

- **скрапперы** собирают данные из внешних источников;
- **core** хранит, индексирует и выполняет поисковые запросы от клиентов;
- **балансировщик** забирает тяжёлые задачи (транскрибация, OCR, эмбеддинги) у источников задач (core и клиентов) и выполняет их на воркерах на GPU;
- **клиенты** держат свою очередь тяжёлых задач (её забирает балансировщик) и обращаются к core за поиском.

Пример использования: спросить LLM «скинь ссылку, я вчера видел видео про asyncio» — модель находит его через SQL-запросы и семантический поиск.

## Модели (на сентябрь 2026)

| Задача | Модель |
|---|---|
| Эмбеддинги | Qwen3-VL-Embedding-2B (BF16) |
| Транскрибирование | whisper large-v3-turbo |
| OCR | PaddleOCR-VL + раскладка |
