# Система сбора, индексации и поиска информации

Система состоит из четырёх частей:

- **скрапперы** собирают данные из внешних источников;
- **core** хранит, индексирует и выполняет поисковые запросы от агента;
- **балансировщик** забирает тяжёлые задачи (транскрибация, OCR, эмбеддинги) только из core, где находятся собственные очереди core и отдельные очереди агентов и выполняет их на воркерах на GPU;
- **[агенты](agent/README.md)** — пользовательские приложения с ИИ-поиском, ручным поиском и Telegram-ботом. Каждый режим зарегистрирован в core под отдельным agent_id со своим владельцем, уровнем доверия и очередью тяжёлых задач. Режимы могут работать в одном контейнере.

Пример использования: спросить LLM «скинь ссылку, я вчера видел видео про asyncio» — ИИ-агент находит его через поисковый API core, используя фильтры и семантический поиск.

Пользователи входят по логину и паролю и работают только со своими записями. Администратор имеет доступ ко всему, управляет пользователями и режимом регистрации (закрытая, открытая или по одноразовым приглашениям). Пользователи создают агентов и скрапперы через свой сайт. Core хранит регистрации и проверяет права; единственный балансировщик получает актуальный список источников задач из core. Подробнее — [пользователи и доступ](core/11_users_and_access.md).

Методы, пути, параметры, заголовки и ответы всех внутренних запросов описаны в [HTTP API](api.md).
