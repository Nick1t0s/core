### 5. Поиск

Запись доступна конкретному агенту в поиске, только если одновременно `record.status = 'done'`, `record.owner = agent.owner` и `record.trust_level < agent.trust_level`. Owner и уровень агента core получает из его серверной регистрации (раздел 11), а фильтры добавляет самостоятельно до поиска и ранжирования. При равных уровнях доступа нет; уровень чужой записи значения не имеет. Записи в `parsing`, `processing` и `error` не ищутся. Внутри записи в `done` ищутся только существующие chunk'и: у file в `error` детей нет, у упавшего собственного text нет chunk'ов.

Агент обращается к поисковому API core из режима ИИ-агента и из ручного поиска. Оба режима доступны в веб-интерфейсе и Telegram-боте и используют одни эндпоинты `GET /api/search/schema`, `POST /api/search`, `POST /api/read`, описанные в [спецификации агента](../agent/README.md). Детали реализации поиска в core остаются в разработке.

HTTP-методы, параметры, заголовок `Authorization: Bearer <agent_id>` и примеры ответов закреплены в [HTTP API](../api.md).
