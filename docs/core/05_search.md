### 5. Поиск

Запись появляется в поиске ровно тогда, когда `record.status = 'done'`. Записи в `parsing`, `processing` и `error` не ищутся. Внутри записи в `done` ищутся только существующие chunk'и: у file в `error` детей нет, у упавшего собственного text нет chunk'ов.

Агент обращается к поисковому API core из режима ИИ-агента и из ручного поиска. Оба режима доступны в веб-интерфейсе и Telegram-боте и используют один контракт `schema`, `search`, `read`, описанный в [спецификации агента](../agent/README.md). Детали реализации поиска в core остаются в разработке.
