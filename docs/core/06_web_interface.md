### 6. Веб-интерфейс core

Веб-интерфейс доступен только из локальной сети. В нём можно:

- смотреть записи в статусе `error`: `error` и `error_detail` записи, а также ошибки и снимки её file;
- смотреть ошибки внутри записей в `done`: file в `error` и упавший собственный text (его ошибка лежит в `error` записи). Только просмотр;
- вручную удалить запись в статусе `error`. Удаляется строка record (всё остальное — каскадом внешних ключей), каталоги в хранилище исходных файлов и в `task_storage` удаляет очистка хранилищ, так как записи больше нет в БД (см. 3.3).

Удалить можно только запись целиком и только в `error`. Удалять отдельные file, а также записи в других статусах нельзя. Перезапуска обработки нет: после удаления скраппер на запрос статуса получает `unknown` и, если снова встретит запись, отправляет её заново как новую (с новым `record_id`). Какие режимы скрапперов встречают запись повторно, описано в разделе «Скрапперы».
